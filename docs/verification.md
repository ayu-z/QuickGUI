## 已发现并修正

TinyCC 多编译单元动态库的全局内部符号 `parse_flags` 与 Apple Heimdal 框架符号碰撞。在引入原生串口和系统证书依赖后，原先可执行的 libtcc 路径出现 SIGBUS。固定源码按上游 `ONE_SOURCE=yes` 构建后，内部符号不再参与此类解析；重新执行真实 C 测试。
