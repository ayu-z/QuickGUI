# 架构与实现契约

## 产品边界

设计器与运行器首期支持 Windows x64、macOS x64/ARM64。桌面采用原生窗口；UI/CODE 针对选中控件或模块实例的属性、视觉样式与状态样式。页面结构由画布和树管理，流程和 C 代码独立编辑。

前端 React/TypeScript 与 Tauri 宿主通信；桌面业务流程由 Rust Engine 执行；C 源码在独立进程通过 libtcc 或提前编译的同 ABI 模块执行。浏览器运行器提供普通流程的便携实现，并对原生能力返回明确错误。

## 单一工程模型

`Project` 是唯一源模型，工作副本统一为 schemaVersion=5、控件 definitionVersion=2，所有可引用对象具有稳定 ID。公开类型在 `src/core/types.ts`，校验与入口规范化在 `src/core/validation.ts`。已知旧文件在打开、恢复或命令行导出时一次性转换，不保留旧版运行分支，也不需要升级确认。未知版本与无效结构严格拒绝。`window/widgets` 表示固定主窗口，必需的 `windows` 数组保存附加窗口。JSON、资源作用域、串口事件、通用数据节点和 FB 命名端口可直接使用；执行线与数据线分别调度，C 状态按块实例隔离。所有窗口共享工程级变量、流程和资源；渲染可投影当前窗口，运行与保存接收完整工程。

局部 CODE 仅接受 `props/style/states`，不能重写对象 ID、类型或树。无效草稿按控件 ID 保留，不进入预览版本。画布、表单和合法 CODE 更新通过同一个事务历史支持撤销/重做。缓存、构建目录和运行记录不作为工程源文件。

控件模块暴露属性，实例覆盖不修改定义；内部定义通过专门模式编辑。实例样式只作用于根控件和其声明结构。父子引用与模块引用在导入/导出时检查循环。

## 通用控件契约

渲染器由设计态、预览态与发布态共用。设计器仅添加选框、拖拽和属性元数据。控件通过 `props`、`style`、`states`、`bindings` 与 `events` 工作，不直接访问设备。

变量快照以稳定 ID 为键，含值、质量和毫秒时间戳。变量名称可更改；宿主数据 API 允许使用 ID 或名称。双向输入先提交写入请求并执行类型检查。`once` 绑定捕获实例首次有效值。

`widgetDefinitions.ts` 定义 14 类控件的属性、初值、运行回退、编辑器、约束、绑定及事件；Inspector、CODE 校验与新版渲染器共用。`definitionVersion: 1` 保留旧语义，2 开启新版容器继承、输入提交、曲线与表格等行为。变量路径使用类型化数组，属性目标使用 JSON Pointer；二者不可混用。运行中的 JSON 路径写入以当前快照为基准原子替换，避免多窗口覆盖兄弟字段。

编辑器以窗口/模块作用域保存多选、主选、草稿和视图。控件拖动按动画帧更新临时 transform，缩放更新当前控件的临时几何样式；流程块拖动保存局部位置草稿。松手后才统一校验并提交工程，形成一条历史；取消手势会丢弃草稿，拖动中间态不进入自动保存或运行器。锁定与隐藏存于 `editor`，运行器忽略。剪贴板审阅固定 ID 映射并校验目标指纹，模型变化后必须重新准备；依赖复用、源主题及代码信任均显式选择，提交为单一事务。

流程拖动的高频状态由独立 `FlowCanvas` 持有，每个动画帧最多合并一次位置更新，松手立即使用最后坐标提交。父编辑器及 FB 属性表单不订阅临时位置或运行高亮，后者经独立 Context 直接更新画布；相同高亮内容、未改动节点和连线的视图与 data 引用、画布配置保持稳定。节点尺寸通知批量更新，连线通过节点索引解析端口；切换流程或卸载清理待执行帧。浏览器与原生运行指纹均排除节点位置、显示标签等外观字段，移动或重命名不取消在途流程；节点配置、端口和连线变更仍使旧执行失效。

流程页与界面页使用相同的工作区列宽：左侧 224px、右侧 304px，1200px 及以下收缩为 190px/280px。流程选择与分组节点库放在左栏，中间使用共享的 43px 画布标题栏和 29px 状态栏，日志只占中间列；右栏复用属性标题与表单间距，正文独立滚动。流程画布的缩放、适应、网格和吸附工具在标题栏操作，通过独立的 React Flow 上下文更新视图，延续拖动与运行高亮隔离；亮暗外观跟随设计器主题，不改工程运行界面主题或工程数据。

## 流程语义

图是 DAG。事件是入口，边按端口路由；条件分支只发送对应 `true` / `false` 输出。普通多输入节点逐条处理消息，不把多个输入静默丢弃为最后一条。执行有取消令牌、激活上限与有界诊断。

节点配置：

| 节点         | 配置                                                                                                              |
| ------------ | ----------------------------------------------------------------------------------------------------------------- |
| event        | trigger=manual/startup/interval，intervalMs                                                                       |
| read/write   | variable、可选 JSON path；write 可选 value，否则透传输入                                                          |
| math         | operation=add/subtract/multiply/divide，operand                                                                   |
| condition    | operator=gt/gte/lt/lte/eq/neq，value                                                                              |
| delay        | ms                                                                                                                |
| log          | message                                                                                                           |
| script       | scriptId                                                                                                          |
| http         | url、method、body                                                                                                 |
| connection   | connectionId                                                                                                      |
| emit         | event                                                                                                             |
| window       | action=open/close/focus，windowId；不能关闭 main                                                                  |
| map（v4）    | operation=value/object/array；ValueRef 提取值、构造对象或逐项映射                                                 |
| append（v4） | variable、path、item、maxItems、maxBytes、order、可选 droppedPath                                                 |
| serial（v4） | action=scan/filter/open/close/listenStart/listenStop/send/setReconnect/resetCounters；有状态操作引用 connectionId |

定时器由原生会话管理；v4 在运行定义变更时取消旧调度，纯外观修订保留有效运行会话。忙时跳过采样 tick，防止积压。显式命令不会通过丢弃策略伪装成功。事件节点按 ID 触发，定时源不会顺带触发同图其他事件入口。

v3 math 拒绝非数值隐式转换；eq/neq 使用 JSON 结构比较，条件分支保留原始输入；write 向后传递实际写入值。所有入口使用同一当前语义。直接 C 测试通过运行控制器执行，要求当前修订已接受；编译失败不能继续执行旧脚本并误报为新脚本结果。

v4 的 `ValueRef` 在固定值、上游消息和稳定变量 ID 之间显式选择，消息/变量路径沿用类型化 JSON 数组；缺失路径是错误。新节点采用 `success` / `error` 端口，错误至少含 `code`、`message` 和 `operation`；没有连接错误出口时记录错误并使该次执行失败。`flowV4.ts` 集中描述配置、端口与引用，编辑器、校验、连接/变量删除保护和剪贴板重映射使用同一元数据。标准节点与 FB 使用同一执行器。

v4 事件增加 `serial` 的 devices/data/state/error 入口，以及动态读取间隔与启用值的 `controlledInterval`。后者默认 1000 ms/关闭，间隔范围 100–86400000 ms；不积压、补发错过的 tick。手动运行只触发手动入口，不构造串口事件。串口数据事件带方向、字节数、无损 HEX、流式 UTF-8 和时间；初次枚举是 snapshot，不计作新设备插入。

## 原生串口会话

每个运行 owner 持有串口服务，子窗口共享该服务；进程级端口占用注册防止两个 owner 竞争打开同一设备。端口 I/O actor 不等待 Engine 锁或满事件队列；异步命令在等待 I/O 时释放引擎锁，并在返回时检查 owner、会话与执行代际。监听属于有生命周期的外部事件源，不通过永不返回的流程节点占住执行队列。

Windows 串口在注册 IOCP、提交首个读取之前设置 `COMMTIMEOUTS` 的首字节返回模式：已有数据立即返回，否则等待首字节；不等待字节间隔或填满接收缓冲区，空闲期间无需轮询。写超时保留，关闭通过取消 I/O；raw 模式仍表示原生读取批次，报文边界应使用 line/length16。收发时间戳分别记录原生读取返回与操作系统接受发送数据的时间，不代表设备确认。USB 芯片及驱动的缓存延迟仍需在指定设备上测量。

已校验流程与拓扑顺序在载入有效工程时缓存，事件激活仅引用不可变计划；热更新完整校验后更换缓存，无效草稿不替换有效计划，运行代际继续隔离旧任务。连续计算节点高亮通知按 16ms 采样，从通知完成时计算间隔，避免慢订阅者使采样失效；延时、通信、C 与网络等等待节点立即通知。内部 activeNodes 始终即时更新，变量写入、日志、错误、业务事件与结束清理保持即时通知。

宿主收到引擎通知后即时更新最新快照缓存、历史与报警记录，并处理窗口生命周期；仅发给 WebView 的完整状态快照由后台发布器合并。首次更新立即调度，每次发布完成后至少间隔 16ms，同时最多保留一个发布中的快照和一个最新快照，无新事件时仍发送最后一次更新。序列化和广播在阻塞工作线程执行，不占用 Engine 锁或异步 I/O 工作线程。发布前检查工程 ID、修订、会话 epoch 和工程代次；前端继续按快照 sequence 拒绝迟到更新，查询与命令响应仍返回当前完整状态。业务 RuntimeEvent 和串口数据事件不合并，逐帧流程处理与记录语义保持一致。

接收缓冲复用分配，通过消费游标逐帧取出载荷；每次原生读取至多整理一次已消费前缀，避免粘包中每解析一帧就搬移尾部。line 模式保存扫描位置，长行分批到达时只扫描新增字节；length16 等待完整长度头与载荷，raw 直接交付本次可用数据。此处借鉴 [SerialWatch](https://github.com/mini-berry/serialwatch/tree/24f8404e0dd1edd6acde4b9daa3f5d393418d9c8) 的接收缓冲与界面聚合思路：参考项目超过 100 字节或空闲超过 40ms 的前端推送，以及前端按接收间隔分组，属于显示策略。QuickGUI 不用该空闲时间判定协议帧，也不在通信流程中加入该等待。

端口描述包含 portName、portType、可空 VID/PID、USB busId/portChain 物理拓扑等。扫描和设备变化使用完整快照及 added/removed/changed；枚举失败保留最后有效快照。VID/PID 支持空值、0–65535 整数或可带 `0x` 的 1–4 位十六进制，两个条件以 AND 组合；未知标识不匹配指定值。

新会话默认 115200/8N1/无流控、raw 接收、自动重连关闭。打开参数仅接受串口设置字段，先读取连接 profile，再用已解析的设置对象覆盖。`framing` 只影响 RX：raw 批次、LF 行或大端 length16；TX 直接发送 UTF-8/HEX 编码结果并追加 none/LF/CRLF，不添加长度前缀。非法 HEX 无写入；编码及行尾后的发送总量最多 65535 字节，部分写入或超时不自动重试。写入成功不等于设备确认。旧 `connection/test_connection` 保持一次性诊断、8N1/无流控及原收发组帧规则。

严格重连仅复用手动成功打开时确认的 VID、PID、规范端口名和 USB 物理拓扑；所有字段必须存在且相同，不以序列号或唯一 VID/PID 替代。缺少拓扑时返回原因并要求手动打开。打开中、已连接及重连中锁定端口、过滤与通信参数。重连恢复监听，不恢复定时发送；停止监听仍可排空并计数接收数据，但不保存这些数据用于恢复后补播。

未处理 RX 队列以 256 批或 1 MiB 为界。过载关闭端口、取消待发送任务和定时发送，锁存 `RX_OVERFLOW` 并暂停重连，需手动打开恢复。控制/故障通知不依赖已满的数据队列。示例显示历史另由通用 append 节点限制为 500 条/512 KiB，淘汰旧记录并累计淘汰量；显示淘汰不等于接收队列过载。停止/关闭工程释放订阅、I/O 和端口占用；仅外观修订保留有效会话，连接设置变更要求手动重开。

`src/core/examples.ts` 注册串口与 USB 助手，生成器和 `examples/*/quickgui.json` 提供相同普通工程。串口助手使用 64 个通用控件和一张多入口图，实现设备选择、参数、监听、收发、历史及控制；USB 助手使用一张图共享发现与通信 FB。`widget.events` 可通过 `{flowId, entryNodeId}` 精确选择手动入口，浏览器、桌面与导出应用均传递同一入口 ID，不改写业务载荷。没有按示例 ID 运行的特殊组件、C 或 React 业务分支。浏览器可运行通用数据流程，原生设备操作明确报告能力缺失，不提供模拟设备。浏览器、PTY 自动化和物理设备验收具有不同证据范围。

## C ABI 与工作进程

C ABI v2 支持 JSON、字符串和数字输入/输出；变量写集与模块状态目前为数字字典，日志使用 UTF-8。头文件定义在 SDK 中。跨进程只交换序列化请求/响应，不传指针、回调地址或文件句柄。未注册变量、只读写入、非有限数值均失败。

工作进程有时间和输出限制，崩溃不会带崩设计器或引擎。每次调用使用可回收进程，逻辑状态由宿主序列化保留。C 写集验证通过后再提交，失败不应用部分变量写入。

`variableAliases` 在宿主请求中声明源代码变量名到本地数字变量 ID 的封闭映射；多个别名共用同一待写槽，保证同次执行读己之写。worker 通过能力协商声明支持，ABI 2 和 C 源码不变，JIT/AOT 共用协议。

开发加载固定提交 TinyCC，发布将同份 C 源码以 CMake/系统编译器构建并链接同一 Rust runner。AOT 清单以源码哈希定位产物，拒绝不匹配的源码。TinyCC 使用上游 `ONE_SOURCE=yes` 避免与 macOS 系统框架内部符号冲突。

## 原生宿主和导出

设计器和预览组分别持有运行会话。每个预览/独立应用组由 `preview` 主窗口持有 Engine、调度与 SQLite；附加窗口只连接已有会话、提交命令与订阅快照，不创建重复的启动/定时源。窗口配置只作用于预览/生成应用。系统不支持的窗口能力返回诊断。图标由工程资产引用，应用和桌面快捷方式图标由发布构建生成。

运行快照的 `windowState` 保存打开窗口 ID、聚焦窗口及独立修订号，普通变量变化不改变窗口修订号。热更新保留已有窗口可见状态，新增窗口按 `openOnStart` 初始化、移除已删除窗口。每个物理窗口保留独立请求代际，业务调用再路由到所属会话；子窗口关闭不取消共享引擎，全组关闭使窗口同步票据与在途请求失效，阻止迟到任务重开窗口。

源码导出包含运行组件、Engine、C SDK、原生宿主及必要构建入口；JSON作为数据文件导入，不插入代码字符串。目标目录必须为空，避免覆盖已有开发工程。运行器不会携带设计器的 Monaco/画布编辑模块。

## 后续扩展接口

已实现的 React 组件包保留 TSX/CSS 源码、属性默认值、事件声明和编译产物；导入先解析验证，信任确认后才运行。ShadowRoot 只做样式隔离。源码导出提取组件文件并提供 esbuild 重建。

SQLite 按工程及运行会话组隔离保存持久变量、变化数值采样、日志和报警；同组主/子窗口共享数据。写入使用有界后台队列与事务，查询前刷新；持久值按稳定ID与类型恢复。报警确认和恢复正常是两个独立动作。

历史范围查询一次最多 16 个数字变量，每条默认 1000/最多 2000 点，总计最多 20000 点。支持 raw/avg/min/max/last、毫秒边界、空桶和截断诊断；avg 是已存有效样本的算术平均。JSON 可持久化，但不会作为数值历史或报警样本。趋势图实时缓存与 SQLite 历史各自使用明确模式。

组件包 v2 保存完整源码、bundle、属性元数据及主题/翻译/资源。跨工程副本保留不可变 `packageIdentity`，本地 ID 独立。嵌入资源优先于别名，别名再映射到工程资源；动态语言与源语言回退分开。组件构建复用工程校验器，`--project/--module` 按本地 ID 原子回填独立工程，构建失败不替换有效 JSON。

工业协议包、复杂可重入子流程、完整 SCADA 报表与冗余、角色权限以及远程多用户协作通过后续独立模块扩展。
