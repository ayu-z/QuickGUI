# 泵站与 FB 调速示例

欢迎页选择 **打开泵站示例**，或打开本目录的 `quickgui.json`。工程直接使用 schema v5、v2 控件和 FB 端口；所有示例流程均可在浏览器预览和桌面运行。

## 运行

1. 点击 **启动循环**，累计循环加一，控制台输出 `Cycle completed`。流程中的执行线控制调用顺序，数据线传递当前次数。
2. 将 **目标转速** 滑块设为 65%，下方 **额定转速** 保持 3000 rpm，点击 **计算转速**：目标转速为 **1950 rpm**，剩余调节量为 **35%**。
3. 将滑块改为 20%、额定转速改为 4500 rpm，再点击计算：结果为 **900 rpm / 80%**。计算按钮每次读取当前参数。
4. 在流程页选择 **FB · 调速计算**，查看双输入数学块、`RPM` / `MARGIN` 双输入双输出结果块，以及 `RPM` 同时连接数值显示和日志的分接线。结果块收到执行信号后，按数据依赖读取参数并计算；数据线本身不触发执行。

计算关系为：目标 rpm = 目标百分比 × 额定 rpm ÷ 100；余量 = 100 − 目标百分比。流程使用普通读取、数学、数据映射、写入及日志节点，无需运行 C。结果初始显示 0，点击计算后更新。

底部 **模拟数据** 开关仅提供示例温度/压力信号，不连接真实设备。原有 C 计数脚本保留在脚本页供桌面版实验，示例按钮不依赖该脚本。

## 编辑与导出

所有控件、变量、命名端口和连线均可在设计器中编辑。生成入口为 `src/core/project.ts`，调速流程位于 `src/examples/pumpSpeed.ts`；本目录保存同一工程的可打开副本。

```sh
node scripts/export-project.mjs examples/pump-station/quickgui.json artifacts/pump-station-runtime
```

导出目录的运行和本机打包步骤见主 README 与 `templates/runtime/README.md`。
